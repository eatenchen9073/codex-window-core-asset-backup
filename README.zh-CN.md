# Codex Window Core Asset Backup

[English](README.md) · [简体中文](README.zh-CN.md)

**为 Codex 项目精选并独立备份真正有助于恢复的核心资产。**

Codex 和 AI Agent 项目会逐渐积累代码、源素材、导出文件和中间版本。这个 Skill 帮助你判断哪些内容关系到理解和接续项目，并记录那些容易在工作窗口结束后遗失的决定和开发经过。

普通的一次性备份会为同一项目准备两个可独立使用的包：**精简包**和**扩展包**。每个包都有自己的 README、项目回顾、清单和恢复说明。扩展包只增加有明确回滚、复用或参考用途的材料。

它也可以比较周期备份、为多个项目或工作窗口整理批次索引，并估算精选备份相对于复制整个项目会新增多少存储占用。它不会自动删除原文件，也不会在未经验证时承诺能在另一台电脑上百分之百复现。

> **版本：** 0.5 Beta

## 核心资产的五类价值

Skill 按资产对恢复项目的价值进行筛选。根据项目情况，核心资产通常包括：

1. **项目脉络与决策**：项目目标、已确认的选择、当前状态、待办事项，以及接续工作所需的背景。
2. **可编辑源文件与依赖**：权威源文件、必要输入、配置，以及修改项目或重新生成产出所需的工具和依赖。
3. **权威交付物**：当前面向用户的成果及必要配套文件，并清楚标明已批准、待审阅或历史版本状态。
4. **证据与来源记录**：来源引用、审阅记录、验证结果和校验值，帮助解释或核验项目成果。
5. **回滚基线**：已确认的基准版本或重要修改前的快照，便于比较变化或恢复关键版本。

精简包保留满足目标恢复层级所需的最小完整集合；扩展包再加入具有明确复用、回滚或参考价值的资产。

## 功能

- **按恢复价值选资产：** 保留权威的可编辑源文件、必要输入和产出、配置，以及理解项目所需的记录。
- **提供两个实用档位：** 精简包保存恢复和继续编辑所需的最小完整集合；扩展包再加入经过挑选的历史基线、有用中间成果、导出物或复核证据。
- **说明重要取舍：** 记录重要资产为何纳入或省略，以及扩展包新增内容的用途。
- **保留项目脉络：** 项目回顾涵盖目标、决定、重要里程碑、当前产出和未完成事项。阶段暂停时可附上交接说明。
- **检查周期变化：** 将当前核心资产与最近一次可访问且已验证的备份比较；没有实质变化时提示无需新备份。
- **整理批次恢复导航：** 可创建项目索引和窗口索引，帮助从工作窗口找到项目包及恢复步骤。
- **说明恢复边界：** 标明备份支持理解项目、查看交付物、重建输出还是继续编辑，并记录已知设置缺口。

## 使用方法

在 Codex 中安装或启用这个 Skill，在需要整理备份时调用。例如：

- “为当前项目创建精简包和扩展包。复制前列出文件选择、估算大小和已知恢复限制。”
- “将当前项目与最近一次已验证备份比较。如果核心内容没有变化，请说明无需新备份。”
- “检查这些项目窗口，整理一个批次索引，把每个窗口链接到对应项目和恢复包。”

需要周期性检查时，再次调用 Skill 即可。Skill 本身不带定时器或计划任务。

## 安装

将本仓库文件夹放入 Codex 技能目录。macOS 或 Linux 的用户级安装目录通常为：

```text
~/.codex/skills/codex-window-core-asset-backup/
```

该文件夹中应包含 `SKILL.md`。确认 Codex 客户端可以读取技能目录；必要时刷新或重启客户端。

## 备份包内容

单项目备份通常包含两个互相独立的包：

```text
项目备份/
├── 精简包/
│   ├── README.md
│   ├── PROJECT-RECAP.md
│   ├── manifest.json
│   └── 已选择的核心资产……
└── 扩展包/
    ├── README.md
    ├── PROJECT-RECAP.md
    ├── manifest.json
    └── 已选择的核心资产与有用补充……
```

扩展包不会复制项目里的所有文件。每项额外内容都应有明确的复用、回滚或参考用途。如果没有值得加入的补充，Skill 应如实说明，而不是为了凑内容而添加文件。

一次整理多个项目或 Codex 工作窗口时，批次根目录可以包含 README、`PROJECT-INDEX.csv` 和 `WINDOW-INDEX.csv`，并在其中放置已完成的项目备份包。

## 存储空间与清理

Skill 可以估算精选备份新增的存储占用，并与复制整个源项目进行比较。这比较的是**本次新增的备份空间**。原项目和旧备份仍保留在原处，因此创建较小的备份包本身不会释放硬盘空间。

Skill 不会删除或清理源文件。请先检查备份；只有你确认原件可以移除并亲自清理后，本机实际占用才会下降。

## 跨电脑恢复

每个备份包都以可转移、可独立使用为目标。包内 README 会说明项目入口、包含的文件、设置要求和已知缺口。实际恢复可能达到不同层级：理解项目、查看交付物、重建输出，或继续编辑开发。

能恢复到什么程度，取决于包内资产、所需应用、依赖和外部服务。除非在干净环境或另一台电脑上实际测试过，备份不代表可以百分之百复现。

## 安全与资产选择

默认排除凭据、Cookie、令牌、`.env` 文件、无关个人文件、缓存和可重新安装的依赖。只有在某文件是唯一可恢复副本或用户明确要求时，才会纳入默认排除的内容。Skill 会复制所选文件，不会移动或删除原件。
