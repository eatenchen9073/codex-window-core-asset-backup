# Changelog

Notable release notes for `codex-window-core-asset-backup`.

## 0.5 Beta

- Provides a recovery-focused workflow for selecting project assets.
- Defines minimal and expanded packages that can each be restored independently.
- Records selection rationale, project history, manifests, restore steps, and known portability gaps.
- Supports periodic comparison with the latest accessible, verified backup and can report when no new backup is needed.
- Supports batch project and work-window indexes.
- Estimates new backup storage compared with copying the complete source project; does not delete original files.
